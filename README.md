# Focus Timer Privacy Policy

## Privacy Policy

morimori studio ("Developer") values your privacy.

### Information Collected

This application does not collect, store, or share any personal information.

The app does not collect:

- Name
- Email address
- Phone number
- Location
- Contacts
- Photos
- Device identifiers

### Local Storage

The app stores the following settings only on your device using SharedPreferences:

- Focus duration
- Break duration
- Sound setting
- Vibration setting

These settings never leave your device.

### Third-party Services

This application does not use:

- Analytics
- Cloud storage
- User accounts
